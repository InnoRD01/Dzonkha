# Dzonga: Himalayan organic tea

A static, single-page brand site. No build step.

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

- `index.html`: page content (Story, Teas, Origin, Ritual, Contact)
- `styles.css`: palette (cream `#fbf3de`, forest green `#314b4a`) and layout
- `script.js`: mobile menu, scroll reveal, newsletter form (front end only)
- `assets/`: emblem, ornaments, band texture and mountain line art, cut from the packaging artwork
